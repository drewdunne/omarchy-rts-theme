# RTS

A deep-space Omarchy theme: navy backgrounds, soft pastel text, and a saturated
blue accent, set against a ringed planet at the edge of a nebula.

![RTS](preview.png)

## Install

```
omarchy theme install https://github.com/drewdunne/omarchy-rts-theme
```

Omarchy generates the terminal, editor, bar and app colors from `colors.toml`.
